# FlavourVault — Recipe REST API

FlavourVault is a REST API built with Python, Django REST Framework,
PostgreSQL, and Docker.

This project is being developed as part of an advanced Django REST
Framework backend course, with a focus on:

- Test Driven Development (TDD)
- REST API design
- PostgreSQL
- Docker & Docker Compose
- Authentication
- API testing
- CI/CD
- Production deployment

## Project Status

Currently under development.

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- Docker
- Docker Compose
- GitHub Actions

More features will be added as development progresses.
